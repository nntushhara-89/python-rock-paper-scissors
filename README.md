
# Rock Paper Scissors

A beginner-friendly command-line game built with Python. Play against
the computer and see who wins!

## Features

- Random computer choices
- Interactive user input
- Win, lose, and tie detection
- Input validation

## Requirements

- Python 3

## How to Run

1. Open the repository in GitHub Codespaces.
2. Open the terminal.
3. Run:

   ```bash
   python main.py
   ```

## Game Rules

- Rock beats scissors.
- Scissors beats paper.
- Paper beats rock.
- Matching choices result in a tie.

## Concepts Practiced

- Lists and functions
- Random selection
- Conditional statements
- String methods
- Input validation
